# Moses Grace Miracle - Student Portfolio and Academic Planner

COS 106 - Introduction to Web Technologies | MIVA Open University | Term Project

A responsive multi-page portfolio website built with HTML, CSS and JavaScript.

## Pages
- `index.html` - Homepage (name, photo, welcome message, biography)
- `about.html` - Education, career aspirations, skills, hobbies
- `projects.html` - Three sample projects
- `planner.html` - Academic planner (add, complete, delete tasks)
- `contact.html` - Contact form with JavaScript validation

## Files
- `style.css` - external stylesheet (responsive, Flexbox and Grid, transitions)
- `main.js` - navigation menu, planner and form validation
- Images, project illustrations and the welcome audio
